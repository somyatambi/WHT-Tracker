# Momentum - Weekly Habit & Task Tracker

Momentum is a personal productivity tracker built with React, TypeScript, and Tailwind CSS. It features weekly task management, habit tracking, progress visualization, and analytics. All data is persisted directly in your browser's \localStorage\.

## Features
- **Weekly Dashboard:** Navigate effortlessly between weeks and view comprehensive stats on tasks and habits.
- **Task Management:** Create, toggle, and delete daily tasks.
- **Habit Tracking:** Set up global habits and track them daily. Check off days and observe your highest streak.
- **Analytics & Visualization:** Analyze completion rates via integrated bar and donut charts (using Recharts).
- **Settings:** Customize whether Sunday or Monday stands as your first day of the week, toggle Dark Mode, and reset data safely.
- **Local Persistence:** Your data never leaves your device thanks to \localStorage\.

## Tech Stack
- React 18
- TypeScript
- Vite
- Tailwind CSS
- Recharts
- date-fns
- lucide-react
- canvas-confetti
